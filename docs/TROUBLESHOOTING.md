# 二维码加载问题修复指南

## 问题描述

在"新增公众号" -> "自动获取" -> "搜索"时，二维码一直显示"加载中..."。

## 已修复内容

1. **前端JavaScript优化**
   - 完善了二维码获取逻辑
   - 添加了更详细的错误提示
   - 新增"重新获取"按钮
   - 添加备用登录方式提示

2. **后端二维码获取优化**
   - 改进选择器匹配逻辑，支持多种二维码元素
   - 添加更详细的日志输出
   - 改进错误处理

3. **添加诊断工具**
   - `diagnose.py` - 检查环境配置
   - `test_login.py` - 测试登录流程

## 诊断步骤

### 1. 运行环境诊断

```bash
python diagnose.py
```

这将检查：
- Python版本
- 依赖包安装状态
- Playwright浏览器安装状态
- 目录结构
- 网络连接

### 2. 测试登录功能

```bash
python test_login.py
```

这将：
- 打开浏览器窗口
- 获取登录二维码
- 显示在控制台
- 等待扫码登录

### 3. 查看详细日志

启动应用后，查看日志输出：
- 控制台输出
- `logs/app.log`

## 常见问题和解决方案

### Q1: Playwright浏览器未安装

**现象**: 
```
Chromium浏览器未安装或无法启动
```

**解决方案**:
```bash
playwright install chromium
```

如果安装失败，尝试：
```bash
playwright install --force chromium
playwright install-deps chromium
```

### Q2: 找不到二维码元素

**现象**: 日志显示"未能获取到二维码URL"

**原因**: 微信公众平台页面结构可能发生变化

**解决方案**: 使用备用登录方式
1. 手动打开浏览器访问 https://mp.weixin.qq.com
2. 扫码登录
3. 登录成功后，会话会自动保存
4. 返回应用重新尝试搜索

### Q3: 网络连接问题

**现象**: 无法访问微信公众平台

**解决方案**:
1. 检查网络连接
2. 检查是否需要代理
3. 确认防火墙设置

### Q4: 端口占用

**现象**: 启动时提示端口被占用

**解决方案**:
修改 `run.py` 中的端口号：
```python
app.run(host="0.0.0.0", port=8080, debug=config.DEBUG)  # 改为8080或其他端口
```

## 使用备用登录方式

如果自动获取二维码失败，可以使用备用方式：

### 方式一：手动浏览器登录

1. 打开浏览器访问 https://mp.weixin.qq.com
2. 使用微信扫码登录
3. 登录成功后，打开浏览器开发者工具(F12)
4. 在Console中运行以下代码获取cookies:

```javascript
document.cookie
```

5. 将cookies保存到 `data/wechat_session.json` (需要按特定格式)

### 方式二：使用手工录入

如果只是想添加公众号而不使用自动搜索：

1. 在"新增公众号"模态框中选择"手工录入"
2. 填写公众号名称（必填）
3. 其他字段可选
4. 点击保存

## 验证修复

1. 重启应用：
```bash
python run.py
```

2. 访问 http://localhost:5000/wechat

3. 点击"新增公众号"

4. 切换到"自动获取"标签

5. 输入公众号名称，点击"搜索"

6. 观察：
   - 如果显示"请先登录"，点击确定
   - 登录模态框应该显示：
     - "正在加载二维码..." -> 成功则显示二维码图片
     - 或显示错误提示和备用登录方式
