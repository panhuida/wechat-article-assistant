# 文章采集时 item_show_type 标题截断功能

## 功能概述

在采集微信公众号文章时，当文章的 `item_show_type` 为 10 时，自动将 `article_title` 截断为前 50 个字符，避免数据库中存储超长标题。

## 实现位置

文件：`src/wechat_article_assistant/services/article_service.py`

方法：`_parse_and_save_articles()`

## 背景说明

### item_show_type = 10 的特点

- **标题超长**：这类文章的标题通常包含完整的文章内容或大段文字
- **文章类型**：图片文章、语音文章、文字卡片等特殊类型
- **数据库影响**：超长标题会占用大量数据库空间，且在界面显示时不美观

### 示例

**原始标题**（超过300字符）：
```
今天才认真读了巴菲特的告别信：

六十多年来，查理对我影响巨大，他是一位极好的老师，也是我保护有加的"大哥"。我们之间虽有分歧，但从无争执。他从不说"我早就跟你说过"。
For more than 60 years, Charlie had a huge impact on me and could not have been a better teacher...
（更多内容）
```

**截断后标题**（53字符）：
```
今天才认真读了巴菲特的告别信：六十多年来，查理对我影响巨大，他是一位极好的老师，也是我保护有加的大哥...
```

## 实现逻辑

### 代码实现

```python
# 获取标题和 item_show_type
title = appmsg.get("title", "")
item_show_type = appmsg.get("item_show_type", "")

# 当 item_show_type 为 10 时，只取标题前 50 个字符
if item_show_type == "10" or item_show_type == 10:
    if len(title) > 50:
        title = title[:50] + "..."
        logger.info(f"item_show_type=10，截断标题: {title}")
```

### 处理规则

| 条件 | 处理方式 | 结果 |
|------|----------|------|
| item_show_type = 10 且 标题长度 > 50 | 截断为前50字符 + "..." | 53字符 |
| item_show_type = 10 且 标题长度 ≤ 50 | 保持原标题 | 原始长度 |
| item_show_type ≠ 10 | 保持原标题 | 原始长度 |

### 数据类型兼容

支持两种数据类型：
- **字符串**：`item_show_type == "10"`
- **数字**：`item_show_type == 10`

这样可以兼容不同版本的微信公众平台API返回的数据格式。

## 与下载服务的协同

### 文章采集阶段（article_service.py）

- **作用**：在数据库中存储简短标题
- **长度限制**：50字符
- **目的**：
  - 减少数据库存储空间
  - 提升界面显示效果
  - 便于文章列表浏览

### 文章下载阶段（download_service.py）

- **作用**：下载文章时从HTML中提取完整标题
- **长度限制**：40字符（用于文件名）
- **目的**：
  - 避免文件名过长导致文件系统错误
  - 确保跨平台兼容性

### 完整流程

```
采集文章 (article_service.py)
    ↓
检测 item_show_type = 10
    ↓
截断标题为 50 字符 → 存入数据库
    ↓
用户选择下载
    ↓
下载文章 (download_service.py)
    ↓
从HTML提取完整标题
    ↓
再次截断为 40 字符 → 用作文件名
```

## 测试用例

### 测试场景

1. **普通文章（item_show_type=0）**
   - 标题：14字符
   - 结果：不截断，保持原样

2. **特殊文章（item_show_type=10，超长标题）**
   - 标题：66字符
   - 结果：截断为53字符（50 + "..."）

3. **特殊文章（item_show_type=10，短标题）**
   - 标题：5字符
   - 结果：不截断，保持原样

### 测试方法

采集一个包含 item_show_type=10 文章的公众号，查看数据库中的标题长度。

## 注意事项

1. **完整信息获取**：虽然数据库中只存储前50字符，但下载时会从HTML中提取完整标题
2. **用户体验**：简短标题更便于在文章列表中快速定位
3. **搜索功能**：前50字符通常包含文章核心关键词，不影响搜索
