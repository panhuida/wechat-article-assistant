# 原文链接功能说明

## 功能描述

在下载的HTML文章中，原文链接已被添加到发布时间和IP归属地信息的右边。

## 显示格式

```
2025-11-15 13:40  北京  https://mp.weixin.qq.com/s/HCvfj4h2GgLrkAHFm_L1Tg
```

## 实现细节

### 1. 普通文章（有meta_content_hide_info元素）

原文链接被添加为一个 `<em>` 元素，插入到 `<span id="meta_content_hide_info">` 容器的末尾。

```html
<span id="meta_content_hide_info">
  <em id="publish_time">2025-11-15 13:40</em>
  <em id="js_ip_wording_wrp"><span id="js_ip_wording">北京</span></em>
  <em class="rich_media_meta rich_media_meta_text" style="margin-left: 10px;">
    <a href="https://mp.weixin.qq.com/s/xxx" target="_blank" style="color: #576b95; text-decoration: none;">
      https://mp.weixin.qq.com/s/xxx
    </a>
  </em>
</span>
```

### 2. 纯图片文章和纯文字文章

对于没有标准meta_content_hide_info元素的文章（如item_show_type=8的纯图片文章和item_show_type=10的纯文字文章），原文链接被直接添加到发布信息div中。

```html
<div style="color: #888; font-size: 14px; margin-bottom: 20px;">
  2025-11-15 13:40  北京  
  <a href="https://mp.weixin.qq.com/s/xxx" target="_blank" style="color: #576b95; text-decoration: none;">
    https://mp.weixin.qq.com/s/xxx
  </a>
</div>
```

## 样式特点

- **链接颜色**: 微信蓝色 (#576b95)
- **文本装饰**: 无下划线
- **打开方式**: 新标签页 (target="_blank")
- **左边距**: 与时间/地点信息保持适当间距

## 修改的文件

- `src/wechat_article_assistant/services/download_service.py`
  - `_inject_publish_info()`: 为普通文章添加原文链接
  - `_process_text_only_article()`: 为纯文字文章添加原文链接
  - `_process_image_only_article()`: 为纯图片文章添加原文链接
  - `download_article()`: 传递article_url参数给相关方法
