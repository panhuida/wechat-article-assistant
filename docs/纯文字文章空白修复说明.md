# item_show_type=10 纯文字文章下载修复说明

## 问题描述

`item_show_type=10` 的文章是特殊的纯文字文章，下载后存在以下问题：
1. **内容无换行**：所有文字挤在一起，无法阅读
2. **发布信息缺失**：发布时间和IP归属地不显示

## 问题原因

### 问题1：内容无换行

标题中的换行符在HTML中是**字面量** `\n`（两个字符），而不是真正的换行符，导致：
- 分段逻辑失效（`split('\n\n')` 无法识别字面量）
- 所有内容被当作一个段落

### 问题2：发布信息缺失

这类文章使用不同的JavaScript变量格式：
- 发布时间：`var createTime = '2025-11-18 22:24'`（不是 `JsDecode` 格式）
- IP归属地：`province_name: JsDecode('广东')`（对象嵌套格式）

原有提取逻辑无法识别这些格式。

## 解决方案

### 解决方案1：换行符转换

在处理标题内容前，将字面量 `\n` 转换为真正的换行符：

```python
# 1. 将字面量的 \n 转换为真正的换行符
processed_title = article_title.replace('\\n', '\n')

# 2. 统一处理不同系统的换行符
processed_title = processed_title.replace('\r\n', '\n').replace('\r', '\n')

# 3. 按双换行符分段
paragraphs = processed_title.split('\n\n')
```

### 解决方案2：增强发布信息提取

扩展 `_inject_publish_info` 方法，支持多种时间格式：

```python
# 提取发布时间 - 支持多种格式
# 格式1：var createTime = '2025-11-18 22:24'
time_match = re.search(r"var\s+createTime\s*=\s*['\"]([^'\"]+)['\"]", html_content)

# 格式2：create_time: JsDecode('...')
# 格式3：create_time = "..."
```

### 解决方案3：动态发布信息显示

从HTML中提取的信息动态生成发布信息提示：

```python
# 提取发布信息
time_match = re.search(r"var\s+createTime\s*=\s*['\"]([^'\"]+)['\"]", response.text)
province_match = re.search(r'province_name:\s*JsDecode\([\'"]([^\'"]+)', response.text)

# 格式化为友好格式
if ' ' in publish_time_str:

    year, month, day = date_part.split('-')

```

## 解决方案

在下载流程中增加特殊处理逻辑：
1. 检测 `item_show_type` 是否为 10
2. 如果是，将标题内容注入到 `js_content` 区域
3. 格式化标题内容为HTML段落

## 实现位置

文件：`src/wechat_article_assistant/services/download_service.py`

方法：`download_article()`

## 实现逻辑

### 1. 检测文章类型

```python
item_show_type_match = re.search(r'item_show_type["\']?\s*[:=]\s*["\']?(\d+)', response.text)
is_text_only_article = False

if item_show_type_match:
    item_show_type = int(item_show_type_match.group(1))
    if item_show_type == 10:
        is_text_only_article = True
        logger.info("检测到纯文字文章（标题即内容）")
```

### 2. 注入标题内容

```python
if is_text_only_article:
    # 查找或创建 js_content 容器
    content_div = soup.find("div", id="js_content")
    if not isinstance(content_div, Tag):
        body = soup.find("body")
        if isinstance(body, Tag):
            content_div = soup.new_tag("div", id="js_content")
            body.append(content_div)
    
    # 清空原有内容
    content_div.clear()
    
    # 将标题内容格式化为段落
    normalized_title = article_title.replace('\r\n', '\n').replace('\r', '\n')
    paragraphs = normalized_title.split('\n\n')  # 双换行分段
    
    for para in paragraphs:
        para = para.strip()
        if para:
            lines = para.split('\n')
            p_tag = soup.new_tag("p")
            p_tag["style"] = "margin: 1em 0; line-height: 1.8; font-size: 16px;"
            
            for i, line in enumerate(lines):
                line = line.strip()
                if line:
                    if i > 0:
                        p_tag.append(soup.new_tag("br"))
                    p_tag.append(line)
            
            content_div.append(p_tag)
```

### 3. 处理流程

```
下载文章
    ↓

    ↓
检测 item_show_type
    ↓
item_show_type == 10?

    │        ↓
    │     清空 js_content
    │        ↓
    │     将标题内容注入

    │        ↓
    │     保存HTML
    │
    └─ 否 → 普通文章

             ↓

```
